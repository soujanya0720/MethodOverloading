# Method Overloading in Java

## Description
This program demonstrates **method overloading** in Java by defining multiple methods with the same name but different parameter lists.

## Concepts Covered
- Method Overloading
- Compile-Time Polymorphism
- Methods with Different Parameters
- Java Classes and Objects

## Technologies Used
- Java

## Sample Output
```text
Sum of two integers: 30
Sum of three integers: 60
Sum of two double numbers: 10.0
```

## How to Run
1. Install the Java Development Kit (JDK).
2. Save the code as `MethodOverloading.java`.
3. Compile using `javac MethodOverloading.java`.
4. Run using `java MethodOverloading`.
